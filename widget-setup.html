아이폰 위젯

원형 계획표와 오늘 할 일을 홈 화면에서 확인하세요.

  1. Scriptable 설치 후 한 번 실행합니다. 무료이며 결제는 필요하지 않습니다.
  2. 아래 코드 복사를 누릅니다.
  3. Scriptable에서 ＋ → 코드를 붙여넣고 이름을 SCEDUL로 저장합니다. ▶ 버튼으로 실행한 뒤 미리보기 크기를 선택합니다.
  4. 아이폰 홈 화면 길게 누르기 → 편집 → 위젯 추가 → Scriptable → 중간 또는 큰 크기를 추가합니다.
  5. 추가한 위젯을 길게 누르고 위젯 편집 → Script → SCEDUL을 선택합니다.

기존 사용자는 색상을 고른 뒤 코드를 다시 복사해 Scriptable의 SCEDUL 코드를 전체 교체하세요. 위젯을 새로 추가할 필요는 없습니다.

코드 직접 선택

위젯을 누르면 사이트에서 수정할 수 있습니다. 위젯 갱신은 iOS가 관리하므로 자정이나 수정 직후에 즉시 바뀌지 않을 수 있습니다. 연결이 끊기면 마지막으로 저장된 기록을 표시합니다.

설치 후에도 홈 화면에서 위젯 길게 누르기 → 위젯 편집 → Parameter에 dark, light, auto를 입력하면 위젯마다 색상을 지정할 수 있습니다. 비워두면 코드 복사 때 선택한 색상을 사용합니다.
